# 光纤通信原理 · 三维交互演示

用 Three.js 做的光纤科普网站：八个章节，每章左侧是可拖动旋转的三维动画，右侧是讲解和可调参数。

| 章节 | 内容 | 可以调的 |
| --- | --- | --- |
| 01 概览 | 光纤束里奔跑的光脉冲，几个关键数字 | — |
| 02 光纤结构 | 纤芯 / 包层 / 涂覆层 / 护套，层层剥开；单模与多模的真实比例截面 | 剥开程度、单独查看某一层、侧视/端面视角 |
| 03 全反射 | 斯涅尔定律、临界角、菲涅尔反射率，倏逝波示意 | 入射角、两种介质折射率、预设组合、自动扫描 |
| 04 传播与数值孔径 | 锯齿形光路、接收锥；超过 αmax 后逐次泄漏 | 入射角、n₁ / n₂、NA 预设 |
| 05 光纤类型与模式色散 | 阶跃多模 / 渐变多模 / 单模同时发射脉冲，比较到达时间；n(r) 分布与输出脉冲图 | 重新发射、速度、轨迹显示 |
| 06 损耗 | U 形弯的弯曲漏光；衰减谱（瑞利散射、红外吸收、水峰）与三个窗口；分贝功率预算 | 弯曲半径、波长、距离、低水峰光纤 |
| 07 信号传输全过程 | 输入文字 → UTF-8 比特 → 激光调制 → 两段光纤（衰减+色散）→ EDFA → 光电检测 → 判决 → 还原文字；示波器波形与眼图 | 文字、波长、码率、每段长度、EDFA、色散补偿 |
| 08 波分复用 | 多波长经合波器进入同一根光纤，再由分波器分开；光谱图与总容量 | 通道数、每路速率 |

键盘 ← → 切换章节，空格暂停；右上角切换深色模式；手机上自动改为上下布局。

## 运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 输出到 dist/
```

推送到 `main` 分支后，`.github/workflows/pages.yml` 会自动构建并发布到 GitHub Pages（需在仓库 Settings → Pages 里把 Source 设为 GitHub Actions）。

## 说明

- 为了看得清，动画里的尺寸、角度差、时间差都做了夸张处理；面板中给出了真实数量级。
- 第 7 章的链路模型是教学用的简化模型：损耗按 dB/km 线性累计，色散展宽按 D·L·B² 估算，噪声按接收功率相对灵敏度的余量换算成 Q 因子。
- 技术栈：Three.js（Line2 粗线、CSS2D 标签、UnrealBloom 辉光）、Vite，界面按苹果式简约设计语言。
